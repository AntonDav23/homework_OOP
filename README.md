# ***Проект по созданию интернет-магазина***

---

## Описание проекта
Набор классов и утилит для моделирования каталога товаров интернет-магазина. Проект реализует структуру для управления товарами и категориями, а также включает автоматический подсчет статистики по всему каталогу.

## Структура проекта
Проект имеет простую и понятную структуру. Весь исходный код находится в папке src.  
  
├── src/  
│   ├── base_product.py   # Базовый(родительский) класс Product  
│   ├── smartphone.py     # Наследник Smartphone  
│   ├── lawnglass.py      # Наследник LawnGrass  
│   ├── category.py       # Логика категорий и итератор  
│   └── __init__.py       # Агрегация импортов пакета   
│  
├── tests/               
│   ├── conftest.py       # Глобальные фикстуры  
│   ├── test_base_product.py  
│   ├── test_smartphone.py  
│   ├── test_lawnglass.py  
│   └── test_category.py  
│
├── main.py               # Точка входа программы  
├── pyproject.toml     
└── README.md  

## Запуск приложения
Основная логика и демонстрация работы находятся в модуле `main.py.`  
Запустить программу можно командой: `python -m src.main`

## Документация
 В рамках данного задания реализован следующий функционал:
1. **Модуль base_product.py**
Содержит Родительский класс: 
- `Product`: Предоставление отдельной единицы товара в каталоге.  

2. **Модули-наследники (`smartphone.py`, `lawnglass.py`)**  
Реализованы два класса-наследника от базового Product для специализации товаров:  
 - Класс `Smartphone`: Расширяет функционал атрибутами производительности (efficiency), моделью (model), объемом памяти (memory) и цветом (color).  
 - Класс `LawnGrass`: Добавляет специфичные поля — страну-производитель (country), срок прорастания (germination_period) и цвет (color).  
3. **Модуль category.py**  
Класс `Category`: Создает объекты категорий, которые агрегируют в себе список товаров (products).  
Имеет собственные атрибуты: name (название) и description (описание).  
Атрибуты класса в `Category`: Реализованы счетчики `category_count` и `product_count`, которые являются общими для всех экземпляров класса. Эти счетчики автоматически обновляются при создании нового объекта Category или добавлении товара через метод add_product.
- Вспомогательный модуль category.py (Итератор)  
Реализован вспомогательный класс CategoryIterator. Он позволяет перебирать товары одной категории напрямую в цикле for, обеспечивая безопасный доступ к приватному списку товаров без нарушения инкапсуляции.  
4. **Магические методы и ограничения**  
- Строковое представление (__str__):  
Для Product реализован вывод вида: Название, X руб. Остаток: X шт.  
Для Category реализован подсчет общего количества единиц товара (quantity) на складе категории.
- Сложение товаров (__add__):  
Доработана функциональность сложения таким образом, чтобы можно было складывать товары только из одинаковых классов продуктов. При попытке сложить разные типы (например, Смартфон и Траву) выбрасывается ошибка TypeError. Для реализации ограничений используется функция type().
 - Защита добавления в категорию:  
Метод add_product доработан так, чтобы не было возможности добавить любой другой объект, кроме экземпляра Product или его наследников. Для реализации ограничений используются функции isinstance().  

5. **Автоматическое тестирование**  
Написаны тесты с использованием фреймворка pytest, которые проверяют:  
- Корректность инициализации объектов классов Product и Category.
- Правильность работы автоматического подсчета количества категорий и товаров.
