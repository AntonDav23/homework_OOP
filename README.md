# ***Проект по созданию интернет-магазина***

---

## Описание проекта
Набор классов и утилит для моделирования каталога товаров интернет-магазина. Проект реализует структуру для управления товарами и категориями, а также включает автоматический подсчет статистики по всему каталогу.

## Структура проекта
Проект имеет простую и понятную структуру. Весь исходный код находится в папке src.  
├── models.py            # Основные классы: Product (Товар) и Category (Категория)  
├── tests/                 
│   └── test_models.py   # Тесты для классов Product и Category  
├── main.py              # Исполняемый скрипт для демонстрации работы программы  
└── README.md  

## Запуск приложения
Основная логика и демонстрация работы находятся в модуле `main.py.`  
Запустить программу можно командой: `python -m src.main`

## Документация
В рамках данного задания реализован следующий функционал:
1. **Модуль Models**
Содержит Классы: 
- `Product`: Создая каждой отдельной единицы товара в каталоге.  
- `Category`: Создает объекты ет объекты товаров с атрибутами: name (название), description (описание), price (цена), quantity (количество).
Используется для представленикатегорий, которые агрегируют в себе список товаров (products).
Имеет собственные атрибуты: name (название) и description (описание).  
- Атрибуты класса в Category: Реализованы счетчики category_count и product_count, которые являются общими для всех экземпляров класса.
Эти счетчики автоматически обновляются при создании нового объекта Category, подсчитывая общее количество категорий и товаров в системе.
2. **Автоматическое тестирование**  
Написаны тесты с использованием фреймворка pytest, которые проверяют:  
- Корректность инициализации объектов классов Product и Category.
- Правильность работы автоматического подсчета количества категорий и товаров.
